# gadz-instruct-lzg

Локальный чат-переводчик для русского и лезгинского языков. Приложение работает на Windows и не требует отправки текста во внешний API.

## Что умеет приложение

- принимает сообщения на лезгинском языке;
- переводит их на русский с помощью NLLB;
- формирует ответ локальной instruct-моделью;
- показывает ответ на русском или переводит его на лезгинский;
- выводит русский ответ по мере генерации;
- озвучивает русский текст через Piper;
- озвучивает лезгинский текст через VITS;
- сохраняет историю текущего диалога в памяти приложения.

## Требования

- Windows 10 или новее;
- Python 3.11;
- видеокарта NVIDIA рекомендуется для быстрой работы Qwen;
- около 3 ГБ свободного места для квантизированной модели Qwen;
- дополнительные файлы моделей, описанные ниже.

## Установка

Клонируйте репозиторий и создайте виртуальное окружение:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Для CUDA-версии PyTorch установите подходящий пакет с официальной страницы PyTorch до установки остальных зависимостей.

## Модели

Файлы весов не включены в Git-репозиторий из-за большого размера. Перед запуском разместите модели в следующих каталогах:

| Каталог | Назначение |
| --- | --- |
| `lezgi-nllb-600m-200k-syntetics/` | Перевод между русским и лезгинским |
| `models/gadz-instruct-lzg-4bit/` | Квантизированная instruct-модель для генерации ответов |
| `models/vits-lez-tts/` | Лезгинская озвучка VITS |
| `models/piper-ru/` | Русская озвучка Piper |

Русская Piper-модель должна содержать файлы `ru_RU-denis-medium.onnx` и `ru_RU-denis-medium.onnx.json`.

У каждой модели могут быть собственные условия лицензии. Проверьте их перед распространением весов вместе с приложением.

## Запуск

Из корневого каталога проекта выполните:

```powershell
.\run_translator.bat
```

Либо запустите напрямую:

```powershell
.venv\Scripts\python.exe translate.py
```

В интерфейсе выберите язык ответа, введите сообщение и нажмите **«Отправить»**. Кнопка **«Озвучить ответ»** воспроизводит последний ответ.

## Архитектура

```text
сообщение на лезгинском
	↓
NLLB: лезгинский → русский
	↓
gadz-instruct-lzg: ответ на русском
	↓
NLLB: русский → лезгинский (если выбран лезгинский)
```

NLLB отвечает только за перевод, а instruct-модель — только за генерацию ответа.
